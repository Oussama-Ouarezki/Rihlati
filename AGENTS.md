# Agent instructions for Rihlati

The instructions for this repository live in **[`CLAUDE.md`](./CLAUDE.md)**. Read that file
before writing any code here — it is not optional context. It contains seven security rules
that are enforced by ESLint and CI, and a required-reading list of what to update in
`obsidian/` whenever code changes.

This file exists only so that agents following the `AGENTS.md` convention find their way
there. It is deliberately a pointer and not a copy: two files claiming to be the rules is how
they drift, and a stale rule is worse than no rule.

`CLAUDE.md` is the canonical name here because it is referenced by name from ESLint rule
messages, code comments, and the documentation vault.
